About us

TIP Gaming Shop is a student project for Introduction to Computing.


What the shop does

It started as a console program that tracked gaming gear stock and sales. We turned it into a website: the pages you see are HTML and CSS, and the logic behind them (login, checkout, restocking, reports) started in C++ and now runs in JavaScript so it can be hosted on GitHub Pages.

Customers can view products and check out. Supervisors, inventory admins and cashiers get extra tools depending on their role.
